# Institute Profile

This repository contains the official profile README and founding charter for the **Institute of Computational Irregularities**.

## To activate as organisation profile

1. Transfer this repository to the organisation `InstituteOfComputationalIrregularities`.
2. Rename it to `.github`.
3. The file `profile/README.md` will then appear on the organisation profile page.
